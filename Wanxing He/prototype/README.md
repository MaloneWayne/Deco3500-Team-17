# The Weekly Split simple demo

Double-click `index.html` to run the prototype. No installation or internet connection is required.

## Demo flow

1. Claim or pass on two receipt items.
2. Review the calculated subtotal and optionally flag protein powder.
3. Spin the wheel for unclaimed dishwasher pods.
4. Choose a pizza portion with the slider.
5. Accept or decline a chore-for-debt trade.
6. Review and save the final settlement.

The left-side guide and start screen remain removed. Each retained feature is presented as one short decision so the demo stays easy to explain.
