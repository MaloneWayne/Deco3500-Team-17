# Deco3500 Team 17 · The Weekly Split

[![Open website](https://img.shields.io/badge/Open_website-The_Weekly_Split-241c16?style=for-the-badge)](https://malonewayne.github.io/Deco3500-Team-17/)

**[打开网站 Open the live website](https://malonewayne.github.io/Deco3500-Team-17/)** — click from this GitHub page. No install needed.

A mobile web prototype for a Sunday sharehouse settlement ritual: receipt draft, orphan spinner, anonymous veto, review re-split, and chore bounties.

## If the link 404s (one-time, repo admin)

GitHub Pages is not enabled on this repo yet. Someone with **admin** access (the repo owner) should:

1. Open [Settings → Pages](https://github.com/MaloneWayne/Deco3500-Team-17/settings/pages)
2. Under **Build and deployment → Source**, choose **GitHub Actions**
3. Open [Actions → Deploy GitHub Pages](https://github.com/MaloneWayne/Deco3500-Team-17/actions/workflows/deploy-pages.yml) and click **Run workflow**

After that, the badge and link above open the site for everyone.

## Local development

```bash
cd weekly-split
npm install
npm run dev
```

Then open `http://localhost:5173/`.
