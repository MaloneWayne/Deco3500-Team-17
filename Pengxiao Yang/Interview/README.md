This folder is for **Pengxiao Yang's** sharehouse interviews for Team 17 (The Weekly Split).

Do not put invented quotes here. Rize Ma's six interviews already exist in [`Ruize Ma/Interview Transcript 01.docx`](https://github.com/MaloneWayne/Deco3500-Team-17/blob/main/Ruize%20Ma/Interview%20Transcript%2001.docx). New transcripts should come from people who actually sat for the questions.

## How to run one

1. Recruit a housemate in St Lucia, Indooroopilly, or Toowong (or another inner-west sharehouse). Studying is fine as a background fact. The user is a housemate, not “a student on campus.”
2. Consent: say the notes go in the team GitHub, names will be P07 / P08 / …, and they can skip a question.
3. Ask the five prompts in [Protocol.md](Protocol.md), in order. Follow up if they stay abstract.
4. Write the transcript the same day, question then answer, in English, as `P07.md`, `P08.md`, …
5. Do not rewrite answers so they “need our app.” If they like Splitwise, write that down.
