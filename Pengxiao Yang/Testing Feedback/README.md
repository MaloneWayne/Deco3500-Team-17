Do not put invented users here. A dry-run by a teammate is not a participant file.

## How to file a session

1. Run Mode A (solo, NPC on) or Mode B (housemates, NPC off) from the Testing Plan.
2. Same day, copy [Session-Template.md](Session-Template.md) to `Test-P1.md`, `Test-P2.md`, …
3. Fill Appendix A–C. Leave a field blank if they skipped it. Do not rewrite answers so they “like the app.”
4. Tag quotes as in Testing Plan section 10.
