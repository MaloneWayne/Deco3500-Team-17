# 12. Initial Design Implications

Based on P1 only, the following design implications should be explored in later tests:

### 1. Strengthen Anonymous Veto

The participant understood the purpose of Anonymous Veto but did not fully trust that their identity would remain hidden.

The interface may need stronger feedback explaining that no participant identity is revealed.

### 2. Add a Limit to the Orphan Spinner

The spinner was acceptable for low-value shared items but was considered inappropriate for expensive purchases.

Possible future design:

- Maximum dollar threshold
- Chore-only option above the threshold
- Group re-vote for expensive orphan items

### 3. Keep Item-Level Claim / Pass

The participant strongly preferred item-level decisions over equal splitting.

This feature should remain central to the prototype.

### 4. Keep LUXURY / COMMUNAL Labels

The participant used these labels to interpret whether an item felt shared or personal.

However, later participants should be tested to see whether these labels influence decisions too strongly.

### 5. Reconsider Fixed Chore Prices

The participant liked chore trading but suggested that assigning a fixed dollar value may create another disagreement.

Future versions could allow the group to approve or negotiate the value.

### 6. Preserve Human Discussion

The participant still wanted a short conversation for high-value purchases.

The Weekly Split should support negotiation rather than completely replace face-to-face discussion.
